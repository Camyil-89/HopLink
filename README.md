# HopLink

HopLink разворачивает цепочку прокси Hysteria2 на Linux-серверах. Трафик идёт от входного узла к следующему серверу и далее до выходного.

![Иконка HopLink](assets/hoplink-icon.png)

Основная инструкция на английском: [README.en.md](README.en.md).

## Требования

- Python 3.10 или новее.
- Go версии, поддерживающей `go 1.26.0` из `go.mod`.
- Доступ по SSH с правами root либо с настроенным `sudo` ко всем серверам.
- Linux-серверы архитектуры `x86_64` или `aarch64`.
- Открытый UDP-порт, по умолчанию `22033`, на узлах цепочки.

Установи Python-зависимости:

```powershell
python -m pip install -r requirements.txt
```

При первой сборке Go может загрузить зависимости проекта. Скрипт кросс-компилирует HopLink из исходников для архитектур серверов.

## Настройка серверов

Скопируй шаблоны в рабочие файлы:

```powershell
Copy-Item deploy/servers.txt.example deploy/servers.txt
Copy-Item deploy/users.txt.example deploy/users.txt
```

В `deploy/servers.txt` укажи серверы по порядку от входного к выходному. Каждая непустая строка содержит четыре поля:

```text
SSH_USER SSH_PASSWORD SSH_HOST SSH_PORT
```

Например:

```text
root пароль_ssh 1.1.1.1 22
root пароль_ssh 2.2.2.2 22
```

Используй реальные данные серверов вместо примеров. Файл содержит SSH-пароли и исключён из Git.

В `deploy/users.txt` укажи клиентов Hiddify — по одному на строку:

```text
имя пароль
```

Пароли должны быть уникальными. Если файла нет, скрипт создаст пользователя `user1` со случайным паролем.

## Развёртывание

Из корня проекта запусти:

```powershell
python deploy_chain.py
```

При первом подключении проверь SSH fingerprint каждого сервера и подтверди его вводом `yes`. Скрипт проверяет доступ ко всем узлам, собирает HopLink из исходников, устанавливает и запускает systemd-сервис `hoplink.service`.

Основные параметры:

```text
--servers PATH       файл SSH-серверов
--users PATH         список пользователей Hiddify
--hy2-sni NAME       SNI; по умолчанию www.cloudflare.com
--hy2-port PORT      UDP-порт; по умолчанию 22033
--remote-dir PATH    каталог на серверах; по умолчанию /opt/hoplink
--delete             остановить сервис и удалить удалённый каталог
```

Полный список параметров доступен через `python deploy_chain.py --help`.

Команда `--delete` останавливает и удаляет сервис на всех указанных серверах.
